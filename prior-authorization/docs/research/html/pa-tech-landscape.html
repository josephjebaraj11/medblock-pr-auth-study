2. Microsoft's multi-agent architecture

A FastAPI dispatcher hands each case to four agents — two run in parallel, then two run sequentially — before a human reviewer sees the result in a Next.js UI.

flowchart TD Case[PA case submitted] --> Dispatch[Dispatcher] Dispatch --> Compliance[Compliance Agent] Dispatch --> Clinical[Clinical Agent] Compliance --> Coverage[Coverage Agent] Clinical --> Coverage Coverage --> Synth[Synthesis Agent] Synth --> Out[Recommendation and
confidence score] Out --> Human((Human reviewer)) style Human fill:#b4530920,stroke:#b45309
Stack: Azure OpenAI GPT-5.4, Microsoft Agent Framework, Azure Container Apps, 5 MCP healthcare-data servers (NPI, ICD-10, CMS coverage, clinical trials, PubMed). Microsoft calls this a proof-of-concept, not a compliant product.

3. AWS reference architecture (Bedrock AgentCore)

AWS's most complete pipeline: an orchestrator detects that a PA is needed, then three specialist agents handle eligibility, documents, and submission — with a mandatory human-approval gate before any decision executes.

flowchart TD Trigger[Order or scheduling call] --> Orchestrator[Orchestrator Agent] Orchestrator --> Elig[Eligibility Agent] Orchestrator --> Doc[Document Agent] Elig --> PAAgent[Prior Authorization Agent] Doc --> PAAgent PAAgent --> Gate{Human approval} Gate -->|approved| Submit[Submit to payer] Gate -->|edited| PAAgent style Gate fill:#b4530920,stroke:#b45309
Security layer (separate AWS post): 4 trust zones — app, API boundary, agent platform (Cedar policies, KMS, PrivateLink), audit layer — the most detailed public HIPAA-agent design of the three hyperscalers.

This template's Gmail/Slack/Sheets integrations have no BAA by default, and n8n itself has no built-in HIPAA certification. This is the path a real incident (unverified in detail) was reportedly linked to.

Key takeaways

PatternWhat it means for a CTO
LLM + rigid rules layer, everywhereNo credible vendor trusts an LLM to know payer rules from memory — all pair it with a lookup/rules engine (CMS policy, CPT/ICD tables).
FHIR as the common data languageMicrosoft, Google, and AWS all build on FHIR-formatted data — see pa-integrations.html for the standards themselves.
Human-in-the-loop is universal among credible playersMicrosoft, AWS, Cohere Health, and Availity all block autonomous denials.
No-code ≠ compliantThe n8n case is the clearest warning: flexibility without platform-level compliance guardrails is a real patient-safety risk.
